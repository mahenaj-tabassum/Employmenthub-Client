# EmploymentHub — Client 💼

### Connection Talent with Opportunity.

EmploymentHub is a full-stack job portal designed to connect job seekers with employment opportunities and help employers streamline their recruitment process.

## 🎯 Project Overview

EmploymentHub aims to simplify the recruitment process by providing a centralized platform where job seekers can explore career opportunities and employers can discover qualified candidates.

## ✨ Key Features

- User registration and authentication.
- Job discovery and browsing.
- Employer and job seeker accounts.
- Job posting and management.
- Candidate applications.
- Recruitment management.

_Features will be documented and updated as development progress._

## 🛠️ Technologies Used

**Frontend**

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- ShadeCN
- Framer Motion

**Authentication**

- BetterAuth

**Backend & Database**

- MongoDB
- Rest API
